# Домашнее задание 2

## Возможности

Код реализует различные варианты отчетов по сотрудникам в зависимости от указанного желаемого типа: 1, 2 или 3.
1. **Иерархия:** для каждого департамента показывает, какие команды в него входят.
2. **Сводка по департаментам:** название, сколько человек,
минимальная и максимальная зарплата, средняя по каждому департаменту.
3. **То же самое, что в "2", но записанное в `departmental_summary.csv`-файл.** 

## Константы, которые могут у вас быть другими:

* `INPUT_PATH` — путь к исходному файлу.
* `OUTPUT_FILE` — путь к файлу с результатом для варианта 3.
