# Домашнее задание 1

В этой папке собраны решения 5 задач по Python.

## Список файлов
* `task_1.py` — решение задачи №1, где один и тот же товар может лежать на складе в Москве, в Казани или в обоих городах.     
* `task_2.py` — решение задачи №2, где дана история поисковых запросов: каждая строка — один введённый запрос. Повтор в списке значит, что этот запрос ввели ещё раз.     
* `task_3.py` — решение задачи №3, где есть список заказов: статус заказа, доставлен покупателю, возврат, сумма заказа.
* `task_4.py` — решение задачи №4, где есть статистика за пять дней работы магазина. У каждого дня число заказов, выручка и число возвратов.       
* `task_5.py` — решение задачи №5, где есть список отзывов на товары.

## Как запустить
Для запуска любого скрипта используйте команду:
```bash
python task_[number].py
