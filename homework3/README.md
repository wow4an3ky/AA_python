# Домашнее задание 3

## Возможности

Код реализует векторизаторы текста и получение важных слов при помощи следующих классов:    
- CountVectorizer: частоты токенов          
- BinaryVectorizer: наличие токенов         
- TfidfVectorizer: веса TF-IDF         
- KeywordExtractor: лучшие n слов по весам токенизаторов       
А также выполняется один из трех сценариев:         
1. **Веса TF-IDF:** создается tfidf как класс TfidfVectorizer при помощь конфига и выводятся слова, idf и матрицы, а также после очистки снова выводится idf.     
2. **Настройки и новый fit():** создается tf как класс TfidfVectorizer с нестандартными параметрами и для различных примеров выводятся слова, idf и TF.
3. **Ключевые слова:** создается объект класса KeywordExtractor и для него выводятся значения метода extract при top_n=2, top_n=1 и top_n=0.
